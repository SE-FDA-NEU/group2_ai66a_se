### Setup for Trakora

## Prerequisites
- Ensure Docker Engine exists and is running (Docker Desktop for Windows/Mac OS, Docker Engine for Linux)
- A copy of .env with valid envs.

## Terminal Commands
```bash
git clone https://github.com/SE-FDA-NEU/group2_ai66a_se.git
cd group2_ai66a_se
docker compose up -d
```
For logs:
```bash
docker compose logs -f
```
Open http://localhost:3000 in any browser.
